About this app

AparaTwo is an offline camera app inspired by BeReal. Capture authentic moments using both front and back cameras simultaneously, without needing an internet connection.

Take full control of your dual photos!
Features include:
• Change and preview the position of the small photo
• Front flash (bright white interface for better selfies)
• Photo gallery preview in the bottom left corner
• Two camera modes (main back / small front AND main front / small back)
• Elegant rounded corners for your photos.

How to install

  1. Download the APK file using the "Free download" button above.
  2. Open your device's Settings and navigate to Security or Privacy.
  3. Enable the option to Install from Unknown Sources (or allow your browser to install apps).
  4. Locate the downloaded file in your Downloads folder and tap it to install.
